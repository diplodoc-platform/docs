# Многоязычные проекты

Если ваша документация переведена на несколько языков, вы можете управлять ею с помощью многоязычного проекта. Такой проект поддерживает несколько версий контента — по одной на каждый язык. Локализованные версии хранятся в одном репозитории и попадают в общую сборку.

## Структура проекта

Пример структуры многоязычного проекта:

```
document-name  # Каталог проекта
├── ru  # Языковая папка
    ├── toc.yaml  # Оглавление
    ├── presets.yaml  # Пресеты переменных
    ├── index.yaml  # Разводящая страница
    ├── _includes/  # Папка с инклюдами
    ├── _images/  # Папка с изображениями
    ├── content-folder/
│       └── file.md  # Файлы и папки с контентом
├── en  # Языковая папка
    ├── toc.yaml  # Оглавление
    ├── presets.yaml  # Пресеты переменных
    ├── index.yaml  # Разводящая страница
    ├── _includes/  # Папка с инклюдами
    ├── _images/  # Папка с изображениями    
    ├── content-folder/
│       └── file.md  # Файлы и папки с контентом
├── es  # Языковая папка
    ├── toc.yaml  # Оглавление
    ├── presets.yaml  # Пресеты переменных
    ├── index.yaml  # Разводящая страница
    ├── _includes/  # Папка с инклюдами
    ├── _images/  # Папка с изображениями    
    ├── content-folder/
│       └── file.md  # Файлы и папки с контентом  
├── .yfm  # Конфигурационный файл, задает параметры сборки и отображения для вашего проекта
```
### Языковая папка

**Языковая папка** содержит полный набор файлов своей языковой версии: оглавление, разводящую страницу, переменные и страницы контента. Файлы внутри папки ссылаются друг на друга.

**Имя языковой папки** — код языка (`ru`, `en`, `es`), те же значения указываются в конфигурации.

**Пути к страницам** в разных языковых папках должны совпадать. Например: `ru/guides/start.md` для русской версии и `en/guides/start.md` для английской. Это помогает платформе Diplodoc корректно связывать языковые версии.

### Файлы проекта

#### .yfm

Конфигурационный файл в корне проекта, общий для всех языков. Помимо общих параметров, в нем указывается список языков — в корневом блоке параметров и в секции `docs-viewer`:

```yaml
langs: ['ru', 'en']  # Массив языков, которые участвуют в сборке.

docs-viewer:
  project-name: my-project
  lang: ru  # Язык для локализации по умолчанию.
  langs: ['ru', 'en']  # Массив языков, которые отображаются в интерфейсе документации. Язык по умолчанию при открытии страницы — первый элемент в массиве.
```

{% note info %}

Коды языков в `langs` должны совпадать с именами языковых папок.

{% endnote %}

{% note warning %}

Языки, не включенные в список, отображаться в интерфейсе не будут.

Если структура проекта содержит языковые папки, обязательно указывайте параметр, даже если в проекте используется только один язык.

{% endnote %} 

Подробнее о `.yfm`: [Настройка YFM-проекта](..\tools\docs\settings.md).

#### toc.yaml

Оглавление языковой версии. В каждой языковой папке — свое оглавление.

Содержимое файлов для разных языков может различаться. Например, если русскоязычная страница не переведена на английский, то ее нет ни в папке `en`, ни в оглавлении для английской версии.

Также вы можете настроить в `toc.yaml` верхнюю и нижнюю навигацию (в блоке `navigation`). Подробнее об этом: [Расширенная навигация](..\project\navigation.md).

{% note warning %}

При переводе оглавления проверяйте не только тексты, но и адреса в блоке `navigation`: ссылки в шапке должны вести на страницы соответствующего языка.

{% endnote %}

#### index.yaml или index.md

Разводящая страница языковой версии, используется для организации навигации по разделам документации. Создается отдельно для каждого языка, форматы — `.yaml` или `.md`. Вы можете создать такую страницу с помощью [Page Constructor](..\project\page-constructor.md).

Читайте подробнее: [Разводящая страница](..\project\leading-page.md).

#### presets.yaml

Значения переменных для языковой версии. В каждой языковой папке — свой файл.

Пример:

- в папке `ru`:

  ```yaml
  default:
    locale: ru
    service-url: https://example.ru
  ```

- в папке `en`:

  ```yaml
  default:
    locale: en
    service-url: https://example.com
  ```

При сборке `not_var{{ service-url }}` заменится на `https://example.ru` для русской версии и `https://example.com` для английской.

Убедитесь, что имена переменных одинаковы во всех языковых папках. Например, если в папке `ru` используется переменная `locale`, в папке `en` тоже должна быть `locale`, а не `region`.

Читайте подробнее: [Пресеты переменных](../project/presets.md).

#### Папки с инклюдами и изображениями

[Инклюды](..\syntax\includes.md) и изображения хранятся в своей языковой папке.

Инклюды содержат текст и переводятся так же, как страницы. 

Изображения дублируются в каждой языковой папке, даже если они одинаковы для всех языков.

## Создание многоязычного проекта

### Шаг 1. Создайте языковые папки

В корне проекта создайте папки для всех языков, на которые переведена документация. Для названий используйте коды языков. Например: `ru`, `en`, `es` и другие.

Чтобы автоматически создать папки для каждого языка, вы можете выполнить команду `yfm init` с параметром `--langs`. Подробнее о команде: [Создание проекта](..\tools\docs\init.md).

### Шаг 2. Настройте языки в .yfm

Откройте файл `.yfm` и укажите список языков в параметре `langs`: в корневом блоке и в секции `docs-viewer`. Язык, который должен открываться по умолчанию, поставьте первым в `docs-viewer.langs`.

### Шаг 3. Добавьте оглавление и разводящую страницу

В каждой языковой папке создайте файлы:

- `toc.yaml` — оглавление.

- `index.yaml` (или `index.md`) — разводящая страница.

### Шаг 4. Настройте пресеты переменных

В каждой языковой папке создайте файл `presets.yaml` и укажите значения для переменных, например, для локали:

```yaml
default:
  locale: ru
```

### Шаг 5. Добавьте контент

Добавьте страницы, инклюды и изображения, повторяя пути других языковых папок. Это поможет платформе Diplodoc корректно связать языковые версии.

### Шаг 6. Соберите проект

После сборки проверьте, что страницы отображаются корректно.

{% note tip %}

Если вы хотите добавить еще один язык в существующий проект, выполните шаги 1–5 для новой языковой папки.

{% endnote %}

## Профилирование

Если часть контента должна отображаться только для определённого языка, используйте условные операторы `if` в тексте:

```
{% if locale == 'ru' %}Перейдите в Госуслуги.{% endif %}
```

А в оглавлении (`toc.yaml`) — условие `when`:

```yaml
- name: Госуслуги
  when: locale == "ru"
  href: gosuslugi.md
```

Подробнее: [Профилирование](..\guides\single-source\profiling.md).

## Переключение между языками

В интерфейсе документации доступен переключатель языков. Меню переключения дает выбрать только те языки, на которые переведена текущая статья.

Если пользователь выберет другой язык, страница перезагрузится: обновятся содержимое, оглавление и интерфейс.

Один и тот же материал в разных языковых версиях доступен по адресам, которые различаются кодом языка:

```
https://diplodoc.com/docs/ru/
https://diplodoc.com/docs/en/
```

## Ссылки на другие языковые версии

Вы можете указать ссылки на другие языковые версии страницы с помощью параметра `alternate` в метаданных. Это помогает поисковым системам определять языковые версии одного материала и показывать пользователю версию на его языке.

Если вы не заполните `alternate` вручную, ссылки на все доступные локализации страницы добавятся автоматически при сборке.

Подробнее — в разделе [Метаданные](..\project\meta.md).

## Логотип для разных языков

Вы можете настроить отдельный логотип для каждого языка. Для этого в [секции docs-viewer](..\settings.md#docs-viewer) файла `.yfm` вместо одного значения укажите коды языков и ключ `default`:

```
docs-viewer:
  logo-options:
    src:
      ru: logo-ru
      en: logo-en
      default: logo
```

В этом примере при переходах по ссылкам с указанием языкового каталога будут отображаться `logo-ru` и `logo-en` для языков `ru` и `en` соответственно. Если языковой каталог не указан, отобразится `logo`.
