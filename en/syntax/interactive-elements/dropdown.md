# Dropdown

Dropdown — a drop-down list. Use it to group elements with hidden content.

{% include [blank-lines](../../_includes/blank-lines-note.md) %}

```markdown
{% list tabs dropdown %}

- Название пункта 1

  Контент для пункта 1.

- Название пункта 2

  Контент для пункта 2.

{% endlist %}
```

**Result:**

{% list tabs dropdown %}

- Name of item 1

  Content for item 1.

- Name of item 2

  Content for item 2.

{% endlist %}
