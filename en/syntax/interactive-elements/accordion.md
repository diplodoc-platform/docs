# Accordion

Accordion allows you to collapse or expand content of your choice, suitable for organizing large amounts of information.

{% include [blank-lines](../../_includes/blank-lines-note.md) %}

```markdown
{% list tabs accordion %}

- Название пункта 1

  Контент для пункта 1.

- Название пункта 2

  Контент для пункта 2.
 
- Название пункта 3

  Контент для пункта 3.

{% endlist %}
```

**Result:**

{% list tabs accordion %}

- Name of item 1

  Content for item 1.

- Name of item 2

  Content for item 2.
 
- Item name 3

  Content for item 3.

{% endlist %}
