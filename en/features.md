# Features

## Extended Markdown

Support for [extended Markdown syntax](syntax/index.md), including:
- code blocks;
- images, videos, and diagrams;
- tables and lists.

## Combining manual and generated documentation

Support for generation from [OpenAPI specifications](guides/openapi.md), as well as auto-generation from Swift and Objective-C.

## Documentation search

Documentation search powered by [Lunr.js](project/lunr.md), with support for integration with the cloud search [Algolia](project/algolia.md). Custom search based on opensearch for the server version.

## Localization

Native support for [text extraction](tools/docs/translate.md) for various translation systems, such as SmartCAT, Weblate, YaCAT, and Yandex Translate.

## Page constructor

Native support for [Page Constructor](https://github.com/gravity-ui/page-constructor) for creating landing pages with carousels, backgrounds, smoothly animated cards, and other block types.

## Right-to-Left mode

Right-to-Left (RTL) mode for languages with right-to-left script (e.g., Arabic, Hebrew).

## Data visualization

Support for visualization tools:
- [Mermaid](custom-plugins/mermaid.md).
- LaTeX.
